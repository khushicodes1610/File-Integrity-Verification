\# File Integrity Verification



A simple file-integrity verification project using SHA-256 hashing.



\## Overview

This project calculates a file's SHA-256 hash and compares it with a previously recorded hash to detect changes.



\## Tools

\- Windows PowerShell

\- Git and GitHub



\## How it works

1\. Calculate and record the original file's SHA-256 hash.

2\. Modify the file and calculate its hash again.

3\. Compare the hashes. If they differ, the file has changed.

4\. Restore the original content and verify that the hashes match.
